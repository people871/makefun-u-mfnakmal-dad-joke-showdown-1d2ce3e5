## The joke

> My kids say my jokes are like our Wi-Fi — they only land when they're standing right next to me.

97 Unicode code points (96 characters + trailing newline), inside the 1–200 gate, one line.

## Why this joke

The judge weighs, in order: is it a dad joke a father would tell, does the pun land cleanly, is it fresh, is it tight, does it read naturally aloud. It is a dad joke in the father's own voice, self-deprecating about his own jokes — the classic dad-joke stance. The pun turns on one word, "land": a joke lands when it works, and Wi-Fi only works when you stand right next to it, so the comparison snaps shut in the last few words with nothing left to explain. It is fresh — not a retread of the fridge-light, flamingo or password jokes — and it reads aloud in one breath, the way a father would deliver it across the dinner table.
